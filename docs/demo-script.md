# W1 演示脚本（2 分钟）

录屏时按这个顺序，全部用仓库里的真实命令，不剪辑。

## 0:00–0:20 一句话

> "这是一个财报研究 Agent 的地基。今天我不演示问答，我演示两样东西：
> 能把数据喂进去，和能给它打分。"

打开仓库，指一下 `pipelines/`、`eval/`、`docs/adr/` 三个目录。

## 0:20–1:00 数据能进来

```bash
make ingest
```

（缓存已热，几秒完成；首次约 6 分钟）

指着输出说：

> "10 家公司、233 份 filing、85,079 条 XBRL 事实、2,865 个 section。
> section 覆盖率 100%——两个 10-Q/A 修正案是单节，属正常。"

补一句坑：

> "第一版解析只有 59% 覆盖。原因是 10-K 每页页眉都在重复 'Item 1'，
> 而且目录和正文的 item 序列完全重复。修法写在 docs/w1-report.md。"

## 1:00–1:30 尺子能量

```bash
make q-check
```

> "30 道题，六类各 5 道。15 道数值题的金标不是手抄的，是拿 tag 回 facts 表
> 重算一遍对账的——手滑打错一位数，这里会直接报错。"

## 1:30–2:00 基线是零

```bash
make eval
```

> "NullAgent 永远回答'无法确认'。所以正确率 0%、引用支撑 0%、误拒率 100%。
> 这三个数必须刚好是这样——如果哪个数不对，说明评测代码有 bug，而不是 Agent 有 bug。
> 下周的 ReAct 版本，就是要跟这个零基线比。"

## 结尾一句

> "所以这个仓库现在的状态是：尺子已经准了，数据已经在了，Agent 还没写。
> 这是我故意的取舍。"
