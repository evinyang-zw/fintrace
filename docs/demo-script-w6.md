# 附录：macOS 录制操作手册

> 这一节是"怎么真的把它录出来"。按顺序做，不要边想边录。

## A. 录制前 30 分钟：把环境清干净

- [ ] 打开**专注模式**（控制中心 → 专注 → 勿扰），关掉微信/钉钉/邮件通知
- [ ] 退出会弹窗的 App；浏览器只留本轮要用的标签页
- [ ] 隐藏书签栏：`Cmd + Shift + B`；隐藏桌面图标（用一个新的空白 Space 录）
- [ ] 接电源，关掉"显示器休眠"；把系统音量调到 0（用 OBS 录系统声时才需要）
- [ ] 浏览器缩放调到 **125%**（`Cmd + +`），保证手机上看字不糊
- [ ] 把 Demo 口令复制到剪贴板（录制时 `Cmd + V` 粘贴，不要手打，画面里也不会出现按键过程）

## B. 先预热线上服务

录制前 10 分钟：

```bash
curl -s http://47.96.253.123/api/health
# 期望四项全 true；再随便提一个问题把 provider 链路预热
```

线上是单实例，provider 抖动时可能 20 多秒才返回。预热一次能明显降低录到"转圈"的概率。

**备用素材**：提前截好三张图——一条完整答案、`/dashboard`、GitHub PR 的门禁评论。
万一现场卡住，切图继续讲，不剪辑掩盖；能讲清楚异常也是加分项。

## C. 录制参数

**方案一：QuickTime（够用，最快）**

1. 文件 → 新建屏幕录制
2. 点录制按钮旁的下拉箭头：麦克风选你的耳机/外接麦；**不要选"无"**
3. 选"录制所选部分"，框一个 1920×1080 的区域（Retina 屏实际会抓 2×，导出仍按 1080p）
4. 录制中不要切 Space、不要开新窗口

**方案二：OBS（更专业，推荐）**

- 画布 1920×1080、30fps；来源 = 屏幕捕获；音频 = 麦克风
- 打开"显示鼠标点击"（可选，讲操作时更清楚）
- 输出 mkv，录完再转 mp4（防崩溃丢文件）

**录音建议**：屏幕用 QuickTime 或 OBS 录，**旁白单独用"新建音频录制"录**，戴耳机防止外放回声。
每段一条音频，命名 `seg1.m4a`…，剪辑时先对齐再调音量。

## D. 分段录（6 段，每段 2–3 条）

| 段 | 时长 | 画面 | 重录标准 |
|---|---|---|---|
| S1 | 25s | 黑底三行字 | 三个坑说清楚即可 |
| S2 | 75s | 线上 Demo：输入口令→提问→引用→trace→待审 | 答案完整出现、引用能点开 |
| S3 | 60s | README 架构图（浏览器） | 四层各讲到一句 |
| S4 | 70s | 评测报告表格 + PR 评论 + holdout 失败行 | 数字不能念错 |
| S5 | 50s | `/dashboard`、`/api/health`、runbook、压测 JSON | 成本与并发数字清楚 |
| S6 | 20s | README 限制段 → 定帧 | 语速放慢收尾 |

**每段开头留 1 秒静音**，结尾留 1 秒，方便剪辑对齐。
**每段重录不超过 3 次**：第 3 次还不行，说明这段台词不顺，改台词，不要硬念。

**S2 的取巧**：多跳问题（Microsoft Cloud）容易慢。可以只录"提问 + 进度条前 2 秒 + 切到已经跑完的答案页"，
中间等待剪掉——但不要伪装成实时完成，旁白说"这里我剪掉了等待"。

## E. 配音技巧

- 语速 **150–170 字/分钟**，比日常说话慢半拍；数字前后各停 0.3 秒。
- 不要"念稿腔"：先默读两遍，再抬头讲；允许"那么、这里"这类自然连接词。
- 环境：小房间、关空调、手机飞行模式；衣柜前/被子旁录音能吸掉回声。
- 一段话里错一个字就重录整段，不要剪成"字字拼接"——听起来会假。

## F. 剪辑（iMovie 或剪映，二选一）

1. 按 S1–S6 顺序拼接；删掉超过 2 秒的等待。
2. **演示过程最多 1.5× 加速**，回答生成过程不要伪造。
3. 关键数字烧字幕（剪映：文本 → 手动加）：
   `99.0%`、`95.0%`、`κ 0.795`、`20 并发 0 个 5xx`、`$0.0006/题`。
4. 不加背景音乐（版权 + 喧宾夺主）。一定要加的话，音量压到 −25dB 以下。
5. 开头 0.5 秒淡入，结尾定格 2 秒（项目名 + GitHub）。
6. 导出：1080p、30fps、H.264、8–10 Mbps，控制在 **≤200MB**。

## I. 六个常见翻车

| 问题 | 处理 |
|---|---|
| 通知弹窗入镜 | 专注模式；录前 5 分钟先开 |
| 答案生成慢/超时 | 预热；备用截图；旁白直接说"这里我剪掉了等待" |
| 口令出现在画面 | 剪贴板粘贴；字段是圆点显示；实在露出就剪辑打码 |
| 麦克风电流声/回声 | 换耳机麦；关外放；衣柜前录 |
| 成片太大 | 降码率到 6 Mbps；或控制在 4:50 |
| 字幕数字写错 | 逐字核对：99.0 / 95.0 / 0.795 / 28.6s |
