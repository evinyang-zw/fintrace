## 0. 结论（先看这五条）

- **50 题金标、6 类、4 个种子**（合并 n=180）：答案正确率 **95.0%**，与手写 ReAct **95.0%** 打平；
  配对差 **0.0pt**，95% CI `[-3.3, +3.9]`。
- **引用语义支撑率 94.4%**（react 90.9%，+3.5pt）。数字引 XBRL 事实做确定性复算，正文引 claim 级 entailment。
- **判官与人工一致**：60 条盲标、二次加权 κ **0.795**；引用 checker 30 条盲标、κ **0.634**。
- **成本 / 延迟**：单题 **$0.00065**（仅 LLM，检索单价未计入，见 §5），p95 **13.0–14.3s**。
- **工程**：185 tests、覆盖率 76.1%、mypy strict、CI 不联网（录制回放）。

## 3. 主结果

### 3.1 编排 A/B（graph vs 手写 ReAct，4 seed 合并）

| seed | react | graph |
|---|---|---|
| 0 | 97.8% | 97.8% |
| 1 | 97.8% | 93.3% |
| 2 | 93.3% | 93.3% |
| 3 | 91.1% | 95.6% |
| **合并（n=180）** | **95.0%** | **95.0%** |

配对 bootstrap（1000 次）：正确率差 **0.0pt**，95% CI `[-3.3, +3.9]` → 换编排未退化。

### 3.2 分类别（4 seed 合并）

| 类别 | react | graph | Δ 95% CI |
|---|---|---|---|
| F1 事实（含引用陷阱） | 100% | 100% | [0, 0] |
| F2 多跳 | 85.0% | **90.0%** | [−3.3, +13.3] |
| C1 计算 | 100% | 100% | [0, 0] |
| C2 对比 | 100% | 92.5% | [−17.5, 0] |
| A1 对抗 | 100% | 100% | [0, 0] |

C2 的差值全部来自 `c2-004`（WMT 用 `net sales` 还是 `total revenue`）——题目本身有口径歧义，
两个 Agent 都会偶尔选错，不是编排差异。

### 3.3 引用、成本、延迟

| 指标 | react | graph |
|---|---|---|
| 引用语义支撑率 | 90.9% | **94.4%** |
| 单题成本（4 seed 均值） | $0.00063 | $0.00065 |
| p50 | 5.5–5.9s | 5.4–5.9s |
| p95 | 12.6–13.8s | 13.0–14.3s |

校验节点每答案多一次 LLM 调用：成本 +3%，p95 +0.6s。**用 +0.6s 换引用支撑 +3.5pt，是这笔交易的全部理由。**

### 3.4 工具边界 A/B（MCP vs 进程内，2 seed）

| backend | 合并（n=60） |
|---|---|
| 进程内 | 98.3% |
| MCP | 96.7% |

配对差 −1.7pt，95% CI `[−6.7, +3.3]`，跨越 0；差异只出现在两道已知口径歧义题。
更硬的证据是接口等价测试：同一参数下，两条路径返回的 observation **逐字节一致**。

## 4. 方法

- **同题配对**：所有比较都在同一批题、同一 seed、同一配置下做，报配对 bootstrap 95% CI，不报两个均值相减。
- **判官校准**：60 条盲标（导出时隐藏机器分），人先独立判；只改 rubric、不改人标，κ 从 0.603 到 0.795。
- **引用校验**：claim 级（句子 + 引用 span），数字走 XBRL 确定性比对，正文走 entailment；30 条 claim 盲标 κ=0.634。
- **NullAgent 反验**：先证明"全拒答"会得到 0% 正确率、100% 误拒，确认尺子本身有效。
- **两段 A/B**：先固定工具边界只换编排，再固定编排只换工具边界——一次只改一个变量。

## 5. 限制（必须和结论一起读）

1. **n 小，且跨 seed 不独立。** 每个 seed 45 道计分题；4 seed 合并成 180 个观测，但只有 45 道不同的题。
   CI 若按 180 独立样本算会偏窄；**单 seed 的区间更保守**。任何小于 2 题的差异都不要解释。
2. **判官不是神。** κ=0.795 表示"和人判得一致"，不表示题目没有歧义；`c2-004` 就是反例。
3. **引用 checker 的 κ=0.634**，误差集中在 `partial` 边界（复合句、来源说明）；引用分适合看趋势，不适合当精确测量。
4. **p95 由 provider 抖动主导**（12.6–14.3s），不能宣称"延迟已优化"；只能说"最坏情况被限住了"。
5. **MCP A/B 只有 2 seed**，统计上只能算旁证；接口等价测试才是主证据。
6. **成本不含 embedding / rerank**（W3 遗留，W5 补单价）。当前 $0.00065/题是 LLM 口径。
7. **离线金标，不是线上流量。** 这些数字说明"在这个 50 题集合上有多好"，不说明真实用户分布。
